## 👨‍💻 Sobre mim

Sou geógrafo e trabalho na interseção entre **clima urbano, saúde pública e geotecnologias**.

- 🔬 **Agora:** estágio de pesquisa no **IRD (França)**, no projeto **TRI4CHAS (CNES/TOSCA)**, cruzando mapas de **Zonas Climáticas Locais (LCZ)** com dados de internações do SUS (SIH/DATASUS) durante **ondas de calor** no Brasil, começando pelo Rio de Janeiro.
- 🎓 **Mestrado:** temperatura de superfície (LST), LCZ e ondas de calor no **Distrito Federal**.
- 📦 **Autor do pacote R [`localdatasus`](https://hendesson.github.io/localdatasus)** (CRAN), que entrega dados do DATASUS espacializados por bairro.
- 🛰️ Interesses: sensoriamento remoto, análise espacial, epidemiologia ambiental, automação de geoprocessamento e dashboards.

| 📦 [**localdatasus**](https://github.com/Hendesson/localdatasus) | Pacote R (CRAN) com dados do DATASUS (SIH, SIM e outros) espacializados por bairro | R |

| 🗺️ [**extracao-dados-SIM**](https://github.com/Hendesson/extracao-dados-SIM) | Extração automática de óbitos do SIM por bairro no estado do RJ (TabNet SES-RJ) | R |
| 🌲 [**Arcpy_Fogo**](https://github.com/Hendesson/Arcpy_Fogo) | Pré-processamento e análise de Áreas Afetadas por Fogo (ICMBio) | ArcPy · GeoPandas · PostgreSQL |
| 📍 [**Arcpy-Kernel**](https://github.com/Hendesson/Arcpy-Kernel) | Kernel Density e Zonal Statistics automatizados | ArcPy |
| 🔥 [**Banco de Queimadas – Boca da Mata**](https://github.com/Hendesson/-Banco-de-Queimadas---Parque-Distrital-Boca-da-Mata) | Sistema web de registro georreferenciado de queimadas (DF) | JavaScript |
| 📚 [**geoprocessamento-arcpy-tutoriais**](https://github.com/Hendesson/geoprocessamento-arcpy-tutoriais) | Tutoriais de geoprocessamento com ArcPy | Python |
| 📌 [**geocodificador-gms**](https://github.com/Hendesson/geocodificador-gms) | Geocodificador em Python com a API do Google Maps | Jupyter |
